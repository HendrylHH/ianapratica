# IA na Prática

Blog estático em português sobre Codex e inteligência artificial, pronto para GitHub Pages.

## Publicar

1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main`, pasta `/ (root)`, e clique em **Save**.

## Estrutura

- `index.html`: abertura do site.
- `guia.html`: sequência de capítulos do Guia Principal.
- `categorias.html`: áreas e subcategorias.
- `categoria.html`: listagem dinâmica da subcategoria escolhida.
- `artigo.html`: modelo de artigo com índice lateral e acompanhamento de leitura.
- `sobre.html`: apresentação de Hendryl Harlacher.

Duplique `artigo.html` para criar novos artigos e atualize os links no Guia Principal ou nas páginas de categoria.
